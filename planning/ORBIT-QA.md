# «Орбита»: решения видны в выпущенной игре

24 октября 2026. Ветка `codex/orbit-decisions`, база main `7f88875`.

Причина замечания: щит уже работал в расчёте столкновений, но корабль выглядел одинаково с ним и без него. Был только небольшой текст под картой. Кроме того, старый checkpoint содержал собственное поле shield без привязки к конкретному релизу. Кнопка «Перезапустить» фактически восстанавливала checkpoint с уже потраченным зарядом.

Теперь вокруг защищённого корабля рисуется оболочка. Над картой видны заряд и решение команды, добавившее щит. При столкновении заряд исчезает, корабль проходит препятствие, сообщение объясняет результат. Следующее препятствие блокирует движение. При переносе функции щита нет. Пропущенная проверка кода по-прежнему позволяет проходить астероиды, и игра явно сообщает об этой ошибке. Замена оформления на щит использует простой вид карты.

«Проверить сохранение» проверяет выпущенную функциональность сохранения; «Новый полёт» возвращает корабль на старт и восстанавливает оборудование текущего релиза. Checkpoint v2 проверяет идентичность заказа, решений, seed и номера завершённого проекта. Неидентифицируемые старые checkpoints сбрасывают только полёт с сообщением; партия студии остаётся.

Проверки:

- `npm run check`, `npm test`: 56 групп, включая 4 новые проверки «Орбиты» и прежние 1269 сценариев движка.
- `npm run build`, `npm run test:hosting`: 4 проверки production-сборки.
- Playwright, изолированные браузерные контексты и реальные результаты движка: shield / swap / focus, видимость оболочки, столкновение, расход заряда, восстановление после закрытия/перезагрузки и новый полёт. Ошибок JavaScript нет.
- Пройден маршрут до трёх батарей и станции.
- Просмотрены скриншоты desktop и mobile; проверены ширины 320, 390, 768, 1024, 1440. Устранено наложение клеток из-за общего min-height кнопок; у диалога нет горизонтального переполнения. На узком экране доступны крупные кнопки направления, помимо маленьких клеток карты.
- Артефакты локально: `outputs/orbit/`, финальные изображения `final-*.png`. Обычное сохранение пользователя не изменялось. Физические телефоны и публичный сервер в эту проверку не входят.
