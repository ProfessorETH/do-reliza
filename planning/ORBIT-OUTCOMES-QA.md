Решения о сроках, сложности, найме, помощи на других задачах, перерывах, благодарности, доплатах, случайных событиях и покупке мебели/компьютеров влияют на производство, бюджет, состояние команды и доступный состав следующих заказов согласно движку. Они не обещают новых способностей корабля. Их действующие эффекты проверяются тестами движка и studio-life; искусственные бонусы к кораблю для этих решений не добавлялись.

Исправлены не только пояснения: добавлены реальные разные элементы карты, обратная связь столкновений, управление границами и раздельные потоки сохранения. Простой вид сохраняет читабельность и основные инструкции. Нет мигающих эффектов; отметка столкновения остаётся до следующего действия. Ошибка записи localStorage отдельно отображается как проблема браузера и не выдаётся за успешно исправленное сохранение.

Проверено:

- 27 комбинаций scope × review × bug через реальный движок на каждом из трёх заказов (81 сценарий). Все маршруты пройдены до победы.
- В Playwright отдельно открыты 27 результатов первой смены. Проверены столкновение, расход щита, сбор батареи, загрузка/закрытие мини-игры и перезагрузка страницы. Ни одной ошибки JavaScript или несовпадения ожидаемого состояния.
- Снимки desktop и mobile просмотрены. Диалог без горизонтального переполнения на 320, 390, 768 и 1440 px. Поддержка сенсорного управления проверена кликами по стрелкам. Реальные телефоны не использовались.
- Искусственный отказ записи localStorage: показана ошибка браузера, нет ложной отметки «Сохранено».
- `npm run check`, `npm test`: 62 группы; `npm run build`, `npm run test:hosting`: 4 группы.

Фикстуры — результаты обычного движка в изолированных контекстах, сохранения пользователя не затронуты. Локальные снимки: `outputs/orbit-outcomes/`. Публичное размещение не выполнялось.
