Доска внутри Space — текущее рабочее состояние. `board-state.json` — последний явно сохранённый снимок в Git. `board.html` — исходник интерактивной доски для восстановления; это HTML-фрагмент для Page, не отдельный сервер и не часть игры.

Статусы: Сделать → В работе → На проверке → Готово. Карточку можно перетащить между колонками или раскрыть и выбрать статус. Исполнитель и заметка меняются внутри карточки. Сохранение состояния выполняет Space. Перенос карточки не запускает Codex и не создаёт commit.

## Фиксация состояния в Git

Когда пользователь просит зафиксировать этап или завершённую задачу:

1. Прочитать свежую доску через Pages. У блока visualize взять полный `metadata.visualization_state.state.modelContent` с `boardVersion: 1` и `tasks`.
2. Сравнить карточки с `board-state.json`; изменения другого участника сохранять. При разногласии о завершённости проверить результат/PR, а не выбирать файл целиком.
3. Записать актуальные задачи в `board-state.json`, обновить время снимка. Не копировать приватные переписки и секреты в заметки.
4. Зафиксировать снимок в ветке задачи вместе с её результатом. После проверки объединить через pull request.

Если состояние Page недоступно, не заменять Git-снимок начальными значениями из HTML и не объявлять синхронизацию выполненной. Автоматического двустороннего обмена и фонового опроса нет.

## Изменение самой доски

Использовать сохранённый исходник и реальный блок визуализации. Перед заменой прочитать и сохранить существующее состояние. После замены сохранить его под новым фактическим file_id, не сбрасывая статусы. Проверить чтение, перенос карточки, узкий экран и повторное открытие.

Начальное разделение исполнителей является предложением. T01 — подключение второго ПК, T02 — диалоги для cicada0133; T03 — баланс для ProfessorETH. Только T11 был завершён при создании доски. Остальные карточки не означают запущенные фоновые задачи.
