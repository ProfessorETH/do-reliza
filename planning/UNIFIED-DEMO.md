## Что согласовано

- Игрок — основатель небольшой студии и её тимлид, включая стартовый экран и вступление.
- Ника следует реальным этапам, учитывает усталость и личные перерывы, объясняет случайные события, доход студии и следующий заказ. На втором заказе подпись и заголовок не называют его первым релизом.
- Во время модальных окон автоход останавливается, голос прекращается; подсказка не начинает говорить поверх окна сотрудника или мини-игры. Tab остаётся внутри открытого окна, включая сюжетное, Escape закрывает его.
- Для существующих сохранений сохранены отдельные ключи обычной и демо-партии. Приём следующего заказа не запускает заново пролог.
- Голос доступен только у первой страницы вступления: ElevenLabs Nataly, 10.44898 с, исходный готовый MP3, без новых запросов. Кнопки повтора не показываются для отсутствующих записей. Краткое происхождение: content/unified-voice-receipt.json. Рабочие браузерные идентификаторы, баланс подписки и локальные диагностические записи не включены в интеграционный результат.
- Сборщик чистит только проверенные дочерние пути внутри dist/demo-v05. Корень остаётся на месте: на Windows его может удерживать Python HTTP-сервер. Две сборки при запущенном сервере прошли после исправления EBUSY.
- У связанных модулей app/engine/demo/office/life/onboarding/sound и новых CSS согласована версия unified-20261024. В браузере была воспроизведена смесь нового экрана со старым пустым voice manifest из кэша; после исправления новый MP3 воспроизводится и состояние «рассказывает» включается.

## Проверка

`npm run check`, `npm test`: 37/37 групп, включая прежние 1269 сценариев. Добавлены проверки подсказок для низкой энергии, отдыха всей команды, случайного события и повторного релиза. `npm run build` проверен на работающем сервере.

Реальный Chromium через stock Playwright CLI, отдельная сессия unified, статическая сборка на 127.0.0.1:5192:

1. Пустое обычное сохранение → новый старт → три страницы истории Ники.
2. Найм Миры, Искры и Эхо, ручная рассадка, предложение плана, начало смены.
3. Совместный разбор, личный перерыв Миры, все технические решения и случайный сбой компьютера. Перезагрузка и «Вернуться в студию» восстановили то же событие.
4. Релиз 95/100, резерв 6 500 ₽; доход студии 6 400 ₽. Мини-игра пройдена стрелками до победы.
5. Принят следующий заказ, команда сохранена, Ника показывает «Заказ 2» без повторного пролога.
6. Проверены 320, 390, 768, 1024, 1440 px: горизонтального переполнения нет; по одной подсказке и панели состояния, магазин помещается по ширине. Скриншоты desktop и mobile просмотрены.
7. Настоящее воспроизведение первого MP3 и его повтор, индикатор речи; на следующей неозвученной странице нет неработающей кнопки повтора. 12 последовательных Tab остаются в сюжетном окне.
8. Быстрый показ ?demo=1 открывает ту же версию с готовой командой, обычное сохранение не меняется. В финальном быстром показе нет ресурсов с HTTP-ошибками. Во всём полном прохождении pageerror не зарегистрированы.

Скриншоты и временные QA-сценарии: outputs/unified/ (исключены из Git). Проверка мобильных размеров проведена в настольном Chromium, не на физических телефонах. Полная озвучка, новые персонажи и строительство дополнительных помещений не заявляются готовыми.
