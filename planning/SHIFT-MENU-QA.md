# Меню смены — 25 октября 2026

Центральное нативное окно показывает готовность, срок и число коллег, которым нужно внимание. Карточки сотрудников содержат реальную активную задачу, прогресс, причины ожидания, энергию, настроение и напряжение. Коллеги, которым нужна помощь, идут первыми, затем работающие. Отдыхающий сотрудник не помечается как требующий ещё одного перерыва. Низкий навык считается поводом для помощи только для активной задачи.

Прямые действия используют существующие обработчики. После одного разбора предложение исчезает. Портрет и «Карточка и забота» возвращают к выбранному сотруднику в офисе. Полный список задач раскрывается отдельно; журнал остаётся доступен. Раскрытие списка и прокрутка сохраняются при обновлении меню.

Открытое окно останавливает авто. Только явное нажатие «Следующий час» в этом окне обходит его собственную блокировку времени; другие диалоги и скрытая вкладка по-прежнему блокируют ход. «Авто в студии» закрывает окно и включает авто. При событии окно смены заменяется окном решения.

Проверено Chromium 1440×900, 390×844, 320×667, 768×1024, 844×390: без горизонтального переполнения, нижний шаг времени внутри экрана. Эмуляция касаний: перерыв уставшей Мире, однократный совместный разбор, следующий час и переход к событию. Авто проверено по фактическому увеличению времени после возврата в офис. Ошибок JavaScript нет. Физический телефон не использовался.
