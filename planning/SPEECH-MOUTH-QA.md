# Движение губ · 25 октября 2026

У шести разработчиков раскрытие рта управляется тем же Web Audio analyser, что и индикатор голоса. Это синхронизация по амплитуде, без распознавания фонем. Атака 32/s, закрытие 24/s, порог тишины 0.025; амплитуда ограничена. Без звука и в текстовом режиме рот неподвижен. При смене говорящего и отмене аудио предыдущий рот закрывается. Reduced motion сохраняет эту локальную подсказку говорящего без добавления кивков.

Для каждой поставляемой головы измерена линия губ в координатах её сетки. При создании персонажа копия геометрии разрезается только вдоль линии смыкания губ, добавляется SpeechOpen и внутренняя поверхность рта. Исходные GLB, текстуры, моргание и скелет не изменены. Раскрытие обрабатывается GPU morph target; в каждом кадре меняются только два коэффициента. Дополнительные GPU-ресурсы освобождаются при удалении сотрудника и сбросе офиса.

Проверки: npm run check; npm test — 217/217; npm run build; npm run test:hosting — 5/5. Семь новых тестов загружают все шесть настоящих GLB и проверяют сохранность нейтральных вершин, UV и моргания, локальность раскрытия, закрытие на тишине, обработку NaN и независимость от частоты кадров. В браузере осмотрены шесть лиц крупным планом, максимальное раскрытие и реальная реплика Эхо; проверены собранный офис и мобильная ширина 390 px, ошибок игры в консоли нет. Это эмуляция телефона, не физическое устройство. Скриншоты и квитанции публикации остаются в игнорируемых output/ и work/.
