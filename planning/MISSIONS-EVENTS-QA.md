# Разные миссии и центральные события

24 октября 2026. Ветка `codex/orbit-missions`, база main `f1ff768`.

## Что изменилось

- Фестиваль сохраняет карту 7×5 и доставку трёх батарей.
- Исследователи: карта 8×6, другая конфигурация астероидов и сплошной ионный барьер. Посещение ретранслятора открывает барьер. Две аномалии нужно явно сканировать на их клетках; для финиша нужны данные обеих аномалий, ретранслятор и две батареи.
- Кубок: карта 9×6, другая конфигурация астероидов, одна батарея и три ворот по порядку. Патруль проходит замкнутый маршрут после каждого хода, включая ожидание. Его следующая клетка отмечена заранее. При перехвате щит расходуется; без щита корабль остаётся на прежней клетке и получает +3 штрафных хода. Золото ≤30, серебро ≤40, иначе бронза. Без щита найден и пройден маршрут на золото за 25 ходов.
- Лучший завершённый маршрут сохраняется в студии; повторная медленная победа рекорд не ухудшает. Рекорды видны в предложениях заказов и переносятся дальше. Денежная награда остаётся оплатой выпуска заказа — повторные полёты не создают бесконечный источник денег.
- Сохранение полёта v3 содержит цели миссии, ретранслятор, ворота, ходы и фазу патруля. Старый полёт фестиваля v2 мигрирует. Старые полёты двух изменённых миссий начинают новую карту с объяснением; студия и решения остаются.

Все события смены теперь открывают отдельный центральный native dialog. Он удерживает фокус, адаптируется к экрану и не сбрасывает автоход. Для срочных noise/computer на normal/hard даётся 45/30 секунд активного времени. Calm, идея и технические решения не ограничены. Последствие истечения написано до выбора: автоматический life-wait, напряжение +10 и настроение −8. Пауза, Escape и отключение таймера доступны; скрытая вкладка и открытое меню останавливают отсчёт. Оставшееся время и пауза сохраняются. Предпочтение «без таймеров» переносится в следующий заказ.

Golos Text загружается из локального файла (184 292 байта). Источник: Google Fonts, `ofl/golostext/GolosText[wght].ttf`; SIL OFL сохранена в `assets/fonts/OFL.txt`. Шрифт включён в статическую сборку, внешние запросы во время игры не нужны.

## Проверено

- 70 групп `npm test`, включая 81 сочетание технических решений и трёх миссий до победы. Новые проверки: обязательные исследования, непроходимость барьера до ретранслятора, порядок ворот, прогноз патруля, штраф/щит, золотой маршрут, миграция полётов, сохранение рекордов и настроек, правила таймера.
- `npm run check`, `npm run build`, четыре проверки `npm run test:hosting`.
- Playwright: все три миссии пройдены до победы через кнопки/клавиатуру с перезагрузкой посередине. Цели и патруль восстановились; рекорд записан в сохранение студии. Ошибок JavaScript нет.
- Через обычные кнопки свежей 3D-демки пройдены две смены: первый релиз → выбор нового заказа → новый план → релиз «Исследователей». Все восемь событий открылись в центральном окне, карта второй миссии появилась; ошибок JavaScript нет.
- Scope, review, bug и life открыты по центру. После решения окно закрывается, autoPlay остаётся true. Проверены пауза, перезагрузка на паузе, отключение таймера, открытие меню и сохранённый отсчёт с 700 мс до истечения: последствие применено ровно один раз.
- Проверены ширины 320, 390, 768 и 1440; у проверенных диалогов нет горизонтального переполнения. Скриншоты просмотрены. В браузере подтверждены загрузка Golos Text и его применение к заголовку события.

Артефакты: `outputs/missions/` (локальные, не входят в Git). Использованы изолированные браузерные контексты и состояния, полученные реальным движком; обычное сохранение пользователя не менялось. Реальные телефоны и публичный сервер не проверялись.
