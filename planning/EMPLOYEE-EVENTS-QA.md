# Случайное событие на сотруднике — 24.10.2026

Случайные `life`-события больше не перекрывают офис автоматически. Их уже сохранённый участник получает красный сигнал с именем над головой. Сцена остаётся доступна: можно осмотреть офис, приблизить сотрудника, нажать на его модель, рабочее место, сигнал или кнопку события в панели. Решения о продукте (`scope/review/bug`) по-прежнему открываются сразу.

Шум: сотрудник подносит руку к уху; сбой компьютера: вопросительный жест открытой ладонью; идея: поднятая рука с небольшим движением. Жест получает только участник события. Посадка, таз и стопы остаются на месте. При reduced motion сохраняется статичная поза, пульсация сигнала отключается. В облегчённом режиме остаётся кликабельный сигнал без скелетной 3D-анимации.

Игровая смена ждёт решения, флаг «Авто» не выключается. Срочный таймер начинает расходоваться после открытия события. Escape и «Вернуться в офис» закрывают окно и останавливают расход времени; открытие продолжает с остатка. Перезагрузка сохраняет событие, сотрудника и остаток, возвращая игрока к сигналу в офисе. После выбора/истечения времени маркер исчезает и автоход продолжается. Ника объясняет нажатие на сигнал; имя и название события доступны скринридеру.

Проверено:

- `npm run check`, 107 групп `npm test`, production build, четыре hosting-проверки.
- Модель: четыре типа инцидентов, стабильный участник после сериализации, отсутствие сигнала для продуктовых решений/чужого участника, снятие после решения, сохранение автохода и бюджета таймера при ожидании.
- Настоящий GLB: разные положения кисти для четырёх событий, неподвижная посадка, отсутствие жеста у другого сотрудника, reduced motion.
- Playwright 1440×1000: событие не открылось самостоятельно, после загрузки 3D осталось 45 000 мс; нажатие на красный сигнал запустило таймер; Escape и перезагрузка сохранили 43 999.9 мс; выбор вернул стадию work, auto=true, сигналов 0. Ошибок JavaScript нет.
- Playwright 390×844: красный сигнал доступен без горизонтального переполнения. Сохранённые 600 мс не расходовались до открытия; после открытия таймер завершился, решение применилось, автоход сохранился, сигнал исчез. Ошибок JavaScript нет.

Локальные скриншоты: `outputs/studio-growth/event-signal-desktop.png`, `event-signal-phone.png` (не входят в Git). Пользовательское сохранение не использовалось: проверки запускались в отдельных браузерных контекстах.

После интеграции #35 сохранены оригинальные голоса и точное соответствие текста Ники существующей записи; инструкция о красном сигнале вынесена в её текстовую подсказку. Конфликт tension показывает сигнал над инициатором, жест двумя ладонями и реплики обоих коллег в окне. Озвучка начинается при открытии и останавливается при закрытии окна.

Дополнительная браузерная проверка после слияния: до клика ни одной реплики персонажа; по сигналу tension проигрывается saga-conflict, в окне подписи Сага/Мира. Escape убирает audio; выбор помощи завершает конфликт (conflictDone=true), stage=work, auto=true. На 390×844 нет ошибок JavaScript и горизонтального переполнения.
