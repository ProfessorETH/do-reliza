# Главная и единая палитра — 24 октября 2026

`assets/studio-theme.css` задаёт общие цвета: ночной сине-серый фон,
янтарное основное действие, тёплый светлый текст и спокойный зелёный статус.
Светлые карточки сотрудников используют один оттенок бумаги. Палитра применяется
к главной, игровым панелям, состоянию коллег, окнам событий, меню и Нике.
Используется уже включённый в проект кириллический Golos Text.

Главная объясняет цель («Собери команду. Выпусти игру.») и три шага.
Справа находится панель запуска: сложность, ресурсы проекта, звук Ники, старт.
При наличии сохранения сразу доступны состояние партии и «Продолжить игру».
Сложность новой истории раскрывается отдельно и не меняет сохранённую партию.
Настройки графики убраны в раскрытие, демо остаётся отдельной ссылкой.

При изменении сложности / включении звука раскрытые разделы сохраняются.
Радиокнопки продолжают работать стрелками клавиатуры. Создание новой истории
поверх существующей по-прежнему требует штатного подтверждения.
На узком экране основная кнопка закрепляется в пределах панели запуска.

Проверка:

- `npm run check`; `npm test` — 74 теста, включая 1269 сценариев движка.
- `npm run build`; `npm run test:hosting` — 4 проверки сборки.
- Playwright: 1440×900, 1366×768, 1024×768, 768×1024, 390×844,
  375×812 и 320×667. На обычном desktop закрытая главная помещается целиком;
  на телефоне страница прокручивается, основная кнопка остаётся доступной.
- Проверены начало новой игры, выбор сложности, воспроизведение MP3 Ники,
  продолжение сохранения, раскрытие новой истории и сохранение старой сложности.
  Отмена подтверждения оставляет прежнюю сложность; подтверждение начинает
  выбранную новую историю. Мобильное вступление Ники сохраняет доступную кнопку продолжения.
- Игровой экран в 1440×900 и 1366×768 помещает задачи и помощь без прокрутки.
  На 390×844 час, помощь и журнал доступны перед прокручиваемым списком задач.
