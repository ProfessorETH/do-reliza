# Оформление вечерней студии

Дополнительный ассет поверх основного офиса: вывеска с акустической деревянной панелью, три настольные лампы, таблички мест, подсветка торца и рамка плаката «Орбита». Столы, кресла, проходы, персонажи и их узлы не заменяются.

- `studio-dressing.blend` — библиотека коллекции `StudioDressing`; добавить через File → Append → Collection в сцену с базовым офисом.
- `recipe.py` — повторяемый рецепт через native Blender MCP. Выполнять в отдельном Python namespace: `setup()`, `sign()`, `lamps()`, `trim()`, `poster()`, `export(project_root)`. Не выполнять общий `art/blender/build.py` ради этого дополнения.
- `receipt.json` — объявленные контакты и измерения реальных мировых bounding box после экспорта. Вывеска, лампа и рамка просмотрены с шести сторон. Все mesh datablock однопользовательские.
- `assets/models/office-dressing.glb` — игровой экспорт; отдельная загрузка сохраняет базовый офис и анимации.
- `assets/office-atmosphere.js` — освещение, контактные тени, процедурная фактура дерева, вечернее окно и иллюстрация плаката. Внешние изображения, генераторы и CDN не нужны. На телефонах дополнительные локальные источники света отключены, основной свет и светящиеся материалы сохраняются.

Поверхность стены: Blender y=3.91; столешницы: z=.80. Контакты проверяются относительно исходной сцены. glTF переводит Z-up в Y-up; координаты навигации остаются в `office-layout.js`. Новый ассет не добавляет препятствий. Временная коллекция была удалена из рабочего Blender после проверки; исходный `.blend` персонажей не сохранялся этой задачей.

Видео и тяжёлые рендеры не запускались. Проверка финального света выполняется в настоящем браузере, где работает игра.
