# Предметы для меню офиса

Карточки показывают WebP-снимки настоящей мебели из `office.glb`, `office-upgrades.glb` и `office-cozy.glb`. Окно предмета использует те же группы в интерактивном Three.js-просмотре. Сцена игры и её навигация не меняются.

Для обновления снимков запусти обычный сервер проекта и открой `art/previews/upgrade-render.html`. Выбери предмет, дождись модели и сохрани WebP в `assets/previews/`. Размер — 720×480, качество WebP .92. В `menu-models.receipt.json` зафиксированы источник, камера и SHA-256 файлов. После изменения мебели обнови снимки и receipt вместе.

Мебель в исходном GLB объединена по материалам. `furniture-preview-parts.js` копирует треугольники нужного участка; исходную геометрию не изменяет. Тихий офис и компьютеры показывают первое рабочее место с соответствующим улучшением. Новые места используют тот же авторский стол, что и расширение офиса.

Снимки дают мгновенный просмотр и работают без WebGL. Интерактивный просмотр загружается только при открытии предмета и освобождает свой контекст при закрытии. Эта служебная страница не входит в публичную сборку.
