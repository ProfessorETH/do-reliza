# Пропорции головы — версия 1

После объединения портретных голов и новых тел пользователь попросил убрать
непропорционально крупные головы. Масштабы подобраны по силуэтам и отношению
ширины причёски к плечам: Мира, Пиксель, Искра 0.76; Норд 0.85; Эхо 0.82;
Сага 0.80; Ника 0.70. Лица и причёски не генерировались заново.

`scripts/fit-head-proportions.js` изменяет только позиции и нормали головы,
а также соответствующие смещения моргания. Выше подбородка применяется
равномерный масштаб; около плоскости воротника Y=1.36 м переход плавно
сохраняет центральный стык шеи. Нормали преобразуются обратной транспонированной
матрицей локальной деформации. Проверяется положительный определитель,
чтобы переход не выворачивал поверхность.

Тела, обувь, кости, inverse bind matrices, пять клипов, UV и текстуры сохраняются.
Исходные байты остаются в GLB, а `recoverHeadProportionBase()` восстанавливает
предыдущую модель с проверкой SHA. Поэтому повторный запуск CLI из свежего
клона не уменьшает голову второй раз.

Пример подготовки новой копии из корня проекта:

```powershell
node scripts/fit-head-proportions.js --id mira --scale 0.76 --input assets/models/mira.glb --output work/mira-proportions.glb
```

`receipt.json` содержит исходные и новые хеши, размеры, масштаб, контроль
стыка и минимальный определитель. Скелеты и посадку дополнительно проверяют
обычные игровые тесты, а `tests/head-proportions.test.js` проверяет все семь
итоговых файлов, моргание и неподвижность защищённого кольца шеи.
