# Новые тела Hunyuan3D 2.1

Игровые модели находятся в `assets/models/`. Шесть сотрудников сохраняют
принятые портретные головы v4, скелет из 25 костей и пять клипов: Idle, Walk,
Sit, Stand, Work. Ника — отдельная модель наставницы, она не входит в найм.
Публичная мастерская после сборки: `/characters.html`.

## Откуда берётся качество

Полные Shape-графы сохранены в `<id>/shape-a.api.json`. Они используют
Hunyuan3D 2.1, а не текстурирование примитивов. Референсы полного роста
получены из исходных портретов; невидимая на портрете нижняя одежда придумана.
Промпты и источники находятся в `references/prompts.json`.

Перед Paint выполняются сварка совпадающих вершин и пять мягких проходов
сглаживания 0.45. У Пикселя отдельно удалена ошибочно сгенерированная плоская
подложка; остальные компоненты не удаляются по общему размерному порогу.
Smart UV экспортируется с настоящим материалом, затем проверяется загрузка
UV через установленный Trimesh. Обычно применяется угол 66° и отступ 0.001;
для Искры и Ники сохранены отдельные исправленные развёртки 45°/0.0005.

Paint использует шесть видов, 768 px, 30 шагов, CFG 3 и атлас 2048 px.
Это параметры генерации видов; они не означают 768-пиксельный атлас.
Нативный локальный Paint API применяется из-за отсутствующего Paint-вызова
в MCP. Правила владения GPU, сохранения результатов и повторных запусков —
в `PAINT-BATCH.md`. Чужие задания не прерываются.

## Сборка и проверки

`rig_hunyuan_body.py` подгоняет поверхность по `rig-fit.json`, переносит веса
на существующие кости и вырезает шею и обувь по измеренным плоскостям.
Поворот на 180° применяется непосредственно к координатам сетки: изменение
Euler у импортированного quaternion-объекта не работало. После открытых
срезов сохраняется исходный порядок граней, чтобы лицевая поверхность
не выворачивалась внутрь. Отображение DoubleSide для маскировки не применяется.

Руки используют непрерывные области весов по поверхности; кольца лодыжек
совпадают с обувью и закреплены за соответствующей стопой. Склейка через
`scripts/attach-hunyuan-body.js` сохраняет принятые голову, кости и клипы
побайтово, а исходную v4-модель можно восстановить из конечного GLB.
Это позволяет повторять сборку после нового клонирования репозитория.

`npm test` проверяет реальные итоговые модели: веса, каждое ребро тела
при деформации, пять клипов, живые позы офиса, подошвы, посадку и маршруты.
После сборки также выполняются `npm run check`, `npm run build` и
`npm run test:hosting`. Визуальная проверка отдельно оценивает лицо,
волосы, одежду и силуэт спереди, в профиль и в движении.

Лицевой анимации, физики волос и анимации отдельных пальцев здесь нет.
Затылок и профиль восстановлены по изображениям приблизительно. Увеличение
числа полигонов само по себе не устраняет ошибки формы или текстуры.
Исходные поколения, отклонённые варианты, GPU-квитанции и промежуточные
экспорты сохраняются локально; в Git включаются итоговые модели, упакованный
Blender-исходник, референсы, скрипты и очищенная сводка происхождения.
