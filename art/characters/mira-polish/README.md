# Мира — доводка в отдельной рабочей версии

Доведена только Мира. После показа в офисе пользователь 25 октября разрешил публикацию, а перед дедлайном выбрал выпуск уже проверенного результата без дальнейшей доводки остальных шести моделей. Публикация проверяется отдельно по серверному release.json и локальному receipt.

Референс: `../portrait-v4/references/mira-portrait.png`. Исходная игровая модель имеет SHA256 `849a50fb5168020d45247fa0092041d440c991c99eca60acf4fdd72d45789dd6`. У неё уже подогнаны пропорции головы. Подготовка всегда начинается с этой базы.

## Что исправляется

- Мягче и компактнее задняя масса волос, медный цвет ошибочно бежевых прядей.
- Непрерывная исходная шея без расширяющейся рваной юбки; центральное лицо, исходные UV и моргание сохраняются. Все UV-копии одной точки двигаются вместе.
- Меньше объём ладоней, спокойнее оттенок кожи. Сохраняются исходные пальцы, их кости и веса; это не новая анатомическая ретопология кистей.
- Очищенная горловина с локально пересобранной верхней полосой свитера.
- Опущенные локти и небольшой наклон корпуса в рабочей позе. Кисти сохраняют цели клавиатуры/мыши, таз и подошвы — свои контакты с креслом и полом.

## Воспроизведение и исходники

`scripts/polish-mira.js` соединяет независимые проверенные изменения головы, кистей и воротника. Исходный BIN остаётся точным префиксом, исходный JSON — в сжатом `miraPolishOriginal`. `recoverMiraPolishBase()` восстанавливает весь предыдущий GLB с проверкой SHA256, в том числе после нового клонирования. Нельзя повторно запускать скульпт на уже изменённой голове.

Подробности native Blender прохода головы: [HEAD-WORKFLOW.md](HEAD-WORKFLOW.md). Подготовка кистей и горловины находится рядом в отдельных Python helpers. Промежуточные GLB, отвергнутые варианты и большие массивы сохраняются в игнорируемой `work/mira-polish/`; они не подменяют финальные игровые ассеты.

Для отдельного редактируемого источника без повторной упаковки всей команды:

```powershell
blender --background --factory-startup --threads 6 --python-exit-code 1 --python art/characters/body-v5/rig_build_team_source.py -- --character mira --output art/blender/mira-polish.blend
```

Живой офисный `.blend` пользователя не меняется. Генерация видео, новые ComfyUI-задания и выгрузка чужих GPU-моделей не нужны.

## Проверка

Сравниваются одинаковые офис, игровой свет, камера и runtime IK. Фронт нужен для горловины и сохранности лица, профиль — для затылка и посадки, крупный план — для кистей. Дополнительно проверяются походка, посадка и работа.

`mira-polish.test.js` проверяет восстановление базы, сохранность лица/UV/скелета, `mira-desk-pose.test.js` — локти и контакты. Прежние проверки всех тел, клипов, посадки и подошв выполняются на реальной итоговой игровой модели.
