# Персонажи команды: скелеты и движения

Мира, Пиксель, Норд, Искра, Сага и Эхо используют настоящие деформирующие скелеты: 25 костей, нормализованные веса, отдельные пальцы. В каждом GLB сохранены `Idle`, `Walk`, `Sit`, `Stand`, `Work` при 30 fps. Проверить их можно в `/art/characters/preview.html`; прежний адрес `/art/hunyuan/preview.html` ведёт туда же.

Исходники собраны в `team-rigged-v3.blend`: шесть моделей, упакованные текстуры и анимации. Это отдельная мастерская; файл офиса не перезаписывается. Итоговые размеры, хеши, число треугольников и источники записаны в `receipt.json`. `export-receipt.json` содержит промежуточные GLB до исправления bind pose и привязки обуви/глаз.

Исходный Hunyuan-скан Миры сохранён без изменений. От него используются джинсы; свитер с цельными рукавами, кисти, обувь, форма головы и волосы построены в Blender. В материалы лиц запечён существующий атлас портретов. У мужских персонажей другой профиль челюсти и крой одежды; у всех различаются лица, волосы и аксессуары. Это стилизованные игровые модели для офисной камеры; точное портретное сходство и крупные планы ещё требуют художественной доводки. Новые diffusion-задания и видео не запускались.

## Пересборка

Из корня проекта, в отдельном процессе Blender:

```powershell
$characterRoot = (Get-Location).Path
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --factory-startup --python art/characters/build_cli.py -- $characterRoot
node scripts/attach-rigid-parts.js
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --factory-startup --python art/characters/pack_source.py -- $characterRoot
node scripts/character-receipt.js
```

Запекание материалов выполняется на CPU. Финализатор сохраняет сырые экспорты в игнорируемую `work/rigid-attachment-before/`, восстанавливает исходную позу из inverse bind matrices и привязывает жёсткую обувь/глаза к костям. Повторный запуск распознаёт готовые GLB и пропускает их. После новой сборки записывается новая квитанция.

В игре `office-skeleton.js` переносит мировые позы управляющих узлов на кости с сохранением исходных осей. `SkeletonUtils.clone` даёт каждому экземпляру независимый скелет. Офис использует процедурную ходьбу и IK, а мастерская воспроизводит сохранённые клипы. Размеры согласованы с существующим офисом: таз стоя 0,88 м, сидя 0,60 м; стопы учитывают настоящую подошву; кисти подстраиваются к клавиатуре/мыши. Сохранены перерывы в кресле зоны отдыха.

Проверки: `npm run check`, `npm test`, `npm run build`, `npm run test:hosting`. Анимационные тесты загружают все шесть GLB, проверяют веса, отдельные скелеты, сохранённую посадку, опору обуви, маршруты к трём столам, смену цели и переходы в зону отдыха при 30/60/120 обновлениях в секунду.
