# Персонажи команды: портреты, скелеты и движения

Мира, Пиксель, Норд, Искра, Сага и Эхо используют настоящие деформирующие скелеты: 25 костей, нормализованные веса, отдельные пальцы. В каждом GLB сохранены `Idle`, `Walk`, `Sit`, `Stand`, `Work` при 30 fps. Проверить их можно в `/art/characters/preview.html`; прежний адрес `/art/hunyuan/preview.html` ведёт туда же.

Текущие тела v5 получены в Hunyuan3D 2.1 по полным референсам персонажей.
Принятые головы сотрудников v4 и существующие анимации сохранены.
Процесс, параметры текстурирования и проверки: [body-v5/README.md](body-v5/README.md).
Редактируемая мастерская всех семи моделей: [team-body-v5.blend](../blender/team-body-v5.blend).
Текстуры упакованы, сохранены 35 Actions. Скелеты открываются в Rest Position;
для воспроизведения Actions переключите их в Pose Position.
Прежние `team-portrait-v4.blend` и `team-rigged-v3.blend` сохранены.
Поверх версии тел v5 выполнена отдельная [подгонка пропорций голов](proportions-v1/README.md).
В этой рабочей ветке отдельно доводится [Мира](mira-polish/README.md): волосы,
шея, кисти и посадка у клавиатуры. Её актуальный редактируемый источник —
[mira-polish.blend](../blender/mira-polish.blend); общая мастерская выше сохраняет
предыдущую Миру и остальные шесть моделей. Новый вариант сначала показывается
пользователю в офисе; автоматической публикации на основном сайте нет.
`receipt.json` и `export-receipt.json` описывают предыдущие версии.

Для v4 построены шесть индивидуальных голов Hunyuan3D2.1 по нейтральным референсам существующих портретов. У каждого своя форма лица, носа, подбородка и объёмная причёска; у Норда и Эхо сохранены разные оправы, у Миры — веснушки и рыжий пучок, у Искры — каре с цветной прядью. Фронтальная текстура совмещена с радужками и линией губ, рельеф волос перенесён на облегчённые сетки. Голова крепится к существующей кости, тело и пять клипов сохранены. Подробный процесс, исходные референсы и квитанции: [portrait-v4/README.md](portrait-v4/README.md). Профиль и затылок восстановлены приблизительно; полного лицевого рига и физики волос нет. Видео не генерировалось.

## Пересборка базового тела v3

Следующие команды пересоздают базовые тела и старые головы. После них нужно повторно присоединить готовые `portrait-v4/<id>/head-detailed.glb` с параметрами из `portrait-v4/assembled/<id>.receipt.json` через `scripts/attach-portrait-head.js`. Для простого редактирования материалов используйте актуальный v4-исходник; регенерировать Hunyuan не требуется.

Из корня проекта, в отдельном процессе Blender:

```powershell
$characterRoot = (Get-Location).Path
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --factory-startup --python art/characters/build_cli.py -- $characterRoot
node scripts/attach-rigid-parts.js
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --factory-startup --python art/characters/pack_source.py -- $characterRoot
node scripts/character-receipt.js
```

Запекание материалов выполняется на CPU. Финализатор сохраняет сырые экспорты в игнорируемую `work/rigid-attachment-before/`, восстанавливает исходную позу из inverse bind matrices и привязывает жёсткую обувь/глаза к костям. Повторный запуск распознаёт готовые GLB и пропускает их. После новой сборки записывается новая квитанция.

В игре `office-skeleton.js` переносит мировые позы управляющих узлов на кости с сохранением исходных осей. `SkeletonUtils.clone` даёт каждому экземпляру независимый скелет. Офис использует процедурную ходьбу и IK, а мастерская воспроизводит сохранённые клипы. Размеры согласованы с существующим офисом: таз стоя 0,88 м, сидя 0,60 м; стопы учитывают настоящую подошву; кисти подстраиваются к клавиатуре/мыши. Сохранены перерывы в кресле зоны отдыха.

Проверки: `npm run check`, `npm test`, `npm run build`, `npm run test:hosting`. Анимационные тесты загружают все шесть GLB, проверяют веса, отдельные скелеты, сохранённую посадку, опору обуви, маршруты к трём столам, смену цели и переходы в зону отдыха при 30/60/120 обновлениях в секунду.
